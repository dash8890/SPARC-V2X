## 1. Three admissible forks (pick one; others stay closed)

### Fork A — Limits / negative result (locked nominal)

**Claim:** Under the frozen nominal SPARC stack, meaningful systematic superiority over LVM is unsupported.

**Work:** Write the limits paper spine from existing evidence (RAO oracle, POPL robustness, closed paths). No new learner.

**Kill / pass:** Pass = honest negative/limits contribution. Fail = only if evidence is later shown to be contaminated in a way that reopens nominal headroom (requires new authorize + fresh seeds).

### Fork B — High packing-pressure problem (regime-conditional)

**Claim:** The scientific target is scheduling under **high packing pressure** (tps4-class), where prior map shows POPL−LVM ≈ +1.33 on 4 seeds—not “beat LVM on nominal d35.”

**Required before any learner:**

1. Predeclare regime definition (arrival intensity / tasks-per-source / contention proxies).
2. Fresh-seed LVM-anchored consequentiality in that regime only.
3. Pass bar: material \(P(\Delta^\star>0)\) and \(E[\Delta^\star\mid >0]\) vs LVM (numeric bars fixed *before* collection).
4. Mechanism must be opportunity-cost / pack composition under contention—not seed anecdotes.

**Hard forbid:** widening task distributions only to manufacture a nominal win while still claiming the old nominal problem.

### Fork C — Deterministic opportunity-cost repair of LVM

**Claim:** LVM’s Lagrangian / scoring is misspecified relative to realized \(J\); a **non-learned** correction can beat LVM.

**Required before claiming win:**

1. Named misspecification (what term LVM ignores that changes \(J\)).
2. One closed-form or search repair; matched eval vs frozen LVM.
3. Same safety/runtime constraints.

**Kill:** if the “repair” is just reintroducing POPL/Direct via a router — already CLOSED.
